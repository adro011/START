# DECISIONS

1. npm instead of pnpm — no admin rights for corepack activation (Program Files EPERM); npm ships with Node and works without elevation.
2. Google Fonts via `<link>` not `next/font` — offline-build safe; `next/font` fetch fails without network during build.
3. No framer-motion initially — CSS-only motion (transform/opacity, Lenis later); add a motion library only when hero/rail work demands it.
4. A11y contrast pass (axe color-contrast, WCAG 2 AA 4.5:1): added `--color-clay: #A93A24` to `@theme` in `src/app/globals.css`. Clay ≈ 6.0:1 as text on paper #FBF6F3 and ≈ 6.3:1 as bg under white text, so it replaces terracotta #D5573B in all text pairings on light surfaces (`text-clay`) and all terracotta fills behind white/light text (`bg-clay`: Sale badges, Subscribe/checkout CTAs, cart-count badges). Terracotta kept only where it is not text: progress bar, dividers, gradient stops, borders, focus rings. On dark ink surfaces (#172121) neither terracotta (4.11) nor umber #7D451B (2.14) passes, so dark-context text uses blush #F2CCC3 (`text-blush`: sale-band eyebrow, footer newsletter error, plus `[&_s]:text-white/70` + `[&_.text-clay]:text-blush` overrides in the home sale band so shared ProductCard price/compare text passes on ink while staying clay on paper). Muted ink steps raised (`/60`→`/80`, `/50`→`/75`, `/45`→`/70`) and `text-neutral-500`→`text-neutral-600` everywhere. Hover states follow the resting color (`hover:text-clay`; terracotta hovers behind light text → `hover:bg-clay`); existing umber hovers kept (white on umber ≈ 7.7:1). No font-size, layout, or copy changes; red-700/green-700 stock notes already pass and were left alone.
